# Images

Drop your files here with EXACTLY these names (they are loaded from `/images/...`):

| File                 | Used for                      | Suggested size      |
| -------------------- | ----------------------------- | ------------------- |
| `profile.jpg`        | Hero portrait (square crop)   | 800 x 800 px        |
| `kilala.png`         | Kilala Emballage screenshot   | 1600 x 1000 px      |
| `f2agc.png`          | F2AGC screenshot              | 1600 x 1000 px      |
| `clinicflow.png`     | ClinicFlow screenshot         | 1600 x 1000 px      |
| `bubble-school.png`  | Bubble School screenshot      | 1600 x 1000 px      |
| `anmougar.png`       | ANMOUGAR screenshot           | 1600 x 1000 px      |

Until a file exists, the site automatically shows the original placeholder.
To add a new project image: put the file here and set `image: "name.png"` on the project in `src/App.tsx`.
